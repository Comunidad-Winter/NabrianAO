# Nabrian AO

Mod Fenix

## Implementaciones

* Programación:

- Sistema de retos (1vs1, 2vs2, 3vs3) por apuesta de oro, elección de ítems, modalidad plantes.
- Eventos automáticos (1vs1, 2vs2, 3vs3 hasta 10vs10) con diferentes modalidades.
- Evento retos automáticos continuos (1vs1, 2vs2, 3vs3, hasta 10vs10)
- Eventos faccionarios (Protector, The team, Capture the flag, the key).
- Evento Juegos del hambre (Cupos ilimitados).
- Sistema de Subastas (Info aquí: https://sites.google.com/site/manualnabrianao/subastas)
- Sistema de retos de clanes, con posibilidad de apostar oro y por los ítem.
- Sistema de usuarios templarios, 10 misiones las cuales recorren todo el mundo del juego, para conseguir ítems de drop y otros logros.
- Sistema de Libros jerárquicos y ítems especiales, Mas información: https://sites.google.com/site/manualnabrianao/libros-y-item-especiales
- Sistema de Misiones: https://sites.google.com/site/manualnabrianao/misiones
- Sistema de Ranking por reputación 250 Usuarios. (La forma de conseguir estos puntos es realizando casi todas las acciones básicas dentro del juego, según la acción conseguirán mas o menos puntos)

* Mapeo, indexación/dateo y Gráfica:

- Mas de 150 item indexados y dateados.
- 173 Gráficos de ambientación indexados.
- Re-mapeados mas de 50 mapas con todo lo necesario para ambientar el mundo.
- Se datearon y balancearon todos los ítem del juego.
